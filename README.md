# NAPPA Infant Sleep Analyzer (ISA 2.0)

NAPPA Infant Sleep Analyzer is cloud-based platform designed to analyze and produce detailed reports of infant sleep based on raw accelerometer and gyroscope features collected from the NAPing PAnts wearable sensor.

With ISA 2.0, there is no software to install or configure locally. The entire analysis pipeline runs in your web browser.

## Features

* Hypnogram and Sleep Depth Trend Generation: Neural network translates movement and respiration based features into continuous sleep depth and discrete sleep-wake states over time.

* Interactive Period Selection: Run fully automated analyses across entire recordings or manually isolate custom sleep windows.

* Multi-Format Export: Export comprehensive visual PDF reports, interactive HTML summaries and time-series data in CSV format ready for external analysis.

## Access & Usage

1. Navigate to the [NAPPA ISA Web Portal](https://isa.nappa.cloud/) and sign in with your existing Google credentials. All authentication is handled securely by google using the [OAUTH 2.0](https://en.wikipedia.org/wiki/OAuth) standard.

2. Upload sleep recording data. Simply drag and drop a sleep recording ZIP folder (or multiple ZIP folders) into the upload zone. Note: The ZIP file should contain a single recording's feature data files that are the associated 'AccFeatures.csv' and 'GyroFeatures.csv' files generated by the wearable.

3. Configure sleep report settings. Before running the analysis, you can fine-tune settings (or use the defaults).

4. Run Analysis, Preview & Download Outputs. Click Analyze to process the data.

## Data Privacy & GDPR Compliance

All participant data, metadata, and uploaded recordings are processed and stored exclusively within Google Cloud's European data infrastructure (europe-north1 in Finland). No data is transferred outside the European Economic Area.

The platform only processes basic identity details (name and email for login validation) and the uploaded anonymous sensor files. Users retain absolute control over their data. You can request the immediate, permanent deletion of your records including logs, profile and uploaded data from our databases by contacting the administrator.
