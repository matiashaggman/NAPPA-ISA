  # NAPPA Infant Sleep Analyzer

NAPPA Infant Sleep Analyzer (ISA) is a tool designed to analyze infant sleep patterns using accelerometer and gyroscope data from the NAPing PAnts wearable developed by BABA Center. The application provides a graphical user interface (GUI) for importing, processing, and analyzing sleep recordings, and generates detailed reports in PDF and CSV formats.

  ## Features

  - Import sleep recordings from ZIP files containing accelerometer and gyroscope data in CSV format.
  - Automatically detect sleep periods and generate detailed reports.
  - Manual selection of sleep periods for report generation.
  - Configurable analysis options including time offset, filtering, and plot settings.
  - Generates multi-page PDF reports summarizing sleep statistics and visualizations.
  - Generates CSV files containing classifier output.

  ## Installation

  1. Clone the repository:
      ```sh
      git clone https://github.com/yourusername/NAPPA-ISA.git
      cd NAPPA-ISA
      ```

  2. Install the required dependencies:
      ```sh
      pip install -r requirements.txt
      ```

  3. Ensure you have PyQt5 installed:
      ```sh
      pip install PyQt5
      ```

  ## Usage

  1. Run the application:
      ```sh
      python nappa_isa_ui.py
      ```

  2. Use the GUI to:
      - Select an input ZIP file containing the sleep recording data (you may drag & drop files to the window).
      - Configure analysis options as needed.
      - Click "Analyze" to start the analysis process.
      - The resulting files will be saved to a .zip archive

  3. The application will generate a PDF report and a CSV file with the analysis results.
      - The PDF contains data visualizations about sleep including: 
        - a sleep depth trend or a hypnogram visualizing the stages of sleep as a function of time
        - baby activity/respiration rate/body position data as functions of time
        - Bar plot/violin plot to visualize the overall distribution of sleep over longer periods.

  ## Project Structure

  - `nappa_isa_ui.py`: Main GUI application file.
  - `nappa_isa_main.py`: Core analysis functions and utilities.
  - `nappa_gui/main_window_ui.py`: UI layout generated by PyQt5.
  - `nappa/preprocess.py`: Data preprocessing and scaling functions.
  - `nappa/pipeline.py`: Functions for reading and processing feature files.
  - `nappa/objects.py`: Classes used to organize the recorded sensor data
  - `nappa/models.py`: Deep learning based classifier used to generate the sleep depth trend & hypnogram based on sensor data
  - `nappa/update.py`: Functions for checking and performing updates.
  - `nappa/resources.qrc`: Resource file for icons and other assets.
