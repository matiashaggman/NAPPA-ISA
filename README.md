# NAPPA Infant Sleep Analyzer (ISA 2.0)

**NAPPA Infant Sleep Analyzer (ISA 2.0)** is a web application designed to analyze infant sleep patterns using accelerometer and gyroscope data from the **NAPing PAnts** wearable developed by the BABA Center. ISA 2.0 offers a web interface for importing, processing, and analyzing sleep recordings, generating detailed reports in PDF, HTML and CSV formats directly in the browser without installations.

---
## Access & Usage

ISA 2.0 has migrated from a standalone Windows executable to a containerized web service.

1. Navigate to the [deployment URL](https://nappa-infant-sleep-analyzer-808342744282.europe-north1.run.app/).
2. Log in using your Google credentials.
3. Import sleep recordings (one or multiple) in zip format, configure report settings & click "Analyze".
4. Resulting sleep report can be previewed and downloaded after analysis completes.
